# ☕ TrackMyChai

TrackMyChai is basically Chai Management System a web-based chai/coffee tracking and billing system developed using ASP.NET MVC.  
It helps organizations, offices, and colleges manage daily tea/coffee consumption and generate billing reports.

---

## 🚀 Features

### 👤 User Side
- User Registration & Login
- Request Tea/Coffee
- Track daily consumption
- View personal bill
- Download bill in PDF format

### 👨‍💼 Admin Side
- Admin Login
- View all user requests
- Manage chai/coffee orders
- Generate full billing reports
- Monthly report with total revenue
- View top users & analytics

## 💡 How It Works

1. User registers and logs in  
2. User places chai/coffee request  
3. Data is stored in SQL Server  
4. Admin monitors all requests  
5. System generates user-wise and monthly billing  
6. Bills can be downloaded as PDF  

---

## 📊 Billing System

- Tea Price: ₹10 per cup  
- Coffee Price: ₹20 per cup  
- User-wise billing  
- Monthly admin report  
- PDF invoice generation
